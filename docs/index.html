Talk out loud and it talks back, in near real time. A voice AI agent powered by Amazon Nova Sonic and Strands Bidi Agents, running on your own laptop.

What it does

A friendly Johannesburg voice companion you chat with out loud. It keeps replies to a sentence or two, suggests things to do in the city, and tells you plainly when it doesn't know.

Real-time voice

Speak naturally and cut in whenever you like. It stops talking and listens, and echo cancellation keeps it from hearing itself through laptop speakers.

Powered by Nova Sonic

Amazon Nova 2.5 Sonic on Amazon Bedrock turns your speech straight into a spoken reply, with no separate transcription or text-to-speech step.

Ready for Kiro

Kiro steering files ship with the repo, so Kiro knows the model, region and house rules from your first prompt.

Run it locally

You need Python 3.12, a microphone and speakers, and an AWS account that can use Amazon Nova 2.5 Sonic. Commands are for Linux and macOS.

  1. Get the code

    git clone https://github.com/Katlego-tech/jozi-voice-buddy.git cd jozi-voice-buddy

  2. Install PortAudio

    Linux only. PyAudio builds against it. On macOS use brew install portaudio.

    sudo apt install portaudio19-dev

  3. Create a virtual environment and install

    No python3.12 command? With uv, use uv venv --python 3.12 .venv and uv pip install -r requirements.txt.

    python3.12 -m venv .venv source .venv/bin/activate pip install -r requirements.txt

  4. Sign in to AWS

    Short-lived credentials through your browser. No access keys to store.

    aws configure set region eu-north-1 --profile jozi-buddy aws login --profile jozi-buddy

  5. Start talking

    Say hi once it's listening. Press Ctrl+C to end the chat.

    python voice_agent.py

Nova Sonic runs in eu-north-1 and us-east-1. To use another profile or region, set AWS_PROFILE or JOZI_BUDDY_REGION before step 5.

Tech stack

Small on purpose: one Python script and a managed speech model.

Python 3.12
Runs the agent on your laptop.
Strands Agents
The Bidi API streams audio both ways at once.

Speech in, speech out, in one model.
Amazon Bedrock
Hosts the model, called from eu-north-1.
